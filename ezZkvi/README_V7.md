# ezZkvi V7 – layout ispravke

Izmjene u odnosu na V6:
- `ezZkvi/Views/Student/Dashboard.cshtml`: četiri brze akcije u `ez-quick-grid` mreži 2 × 2; izolovana CSS klasa za kartice.
- `ezZkvi/Views/Home/Index.cshtml`: zadržan samo uvod i tri funkcionalne kartice prema posljednjoj korisnikovoj verziji; opis desno od naslova.
- `ezZkvi/wwwroot/css/ez-refinements-v7.css`: stilovi za dvije izmjene, uključujući prilagođavanje tabletima i mobitelima.
- `ezZkvi/Views/Shared/_Layout.cshtml`: novi stylesheet se učitava posljednji.

Backend, modeli i migracije ostali su neizmijenjeni. Fajlovi su namijenjeni za Visual Studio / ASP.NET Core. Pokrenuti build i pregledati desktop/mobilni prikaz lokalno.
